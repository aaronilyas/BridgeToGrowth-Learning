Installers

Nothing else has to be installed first. Each computer builds its own installer, and only these four files are published.

Matches this computer

Windows

Windows 10 or 11 · 64-bit (x64)

Setup wizard. It adds a Start menu entry and an optional desktop shortcut.

BridgeToGrowthLearning-Setup-x64.exe

Install steps
  • Run the downloaded file and follow the wizard.
  • Install for yourself, which needs no administrator rights, or for everyone.
  • The wizard installs the Microsoft Edge WebView2 runtime if Windows does not already have it. Windows 11 includes it.
  • Uninstall later from Settings → Apps.

Matches this computer

macOS

Apple silicon (arm64)

Disk image. Open it and drag the app into Applications. There is no Intel Mac installer.

BridgeToGrowthLearning-macOS-arm64.dmg

Install steps
  • Open the disk image.
  • Drag BridgeToGrowth Learning into Applications.

Matches this computer

Linux .deb

Ubuntu, Debian, and Linux Mint · 64-bit (amd64)

Package that adds an app menu entry and installs the GTK and WebKitGTK libraries the window needs.

BridgeToGrowthLearning-amd64.deb

Install steps
  • Double-click the package to open it in your software center, then choose Install.
  • Or from a terminal: sudo apt install ~/Downloads/BridgeToGrowthLearning-amd64.deb
  • Remove it in the software center, or with sudo apt remove bridgetogrowth-learning.

Matches this computer

Linux AppImage

Other Linux · 64-bit (x86_64)

Portable build. Nothing is copied into the system. It uses the WebKitGTK 4.1 libraries already installed.

BridgeToGrowthLearning-x86_64.AppImage

Install steps
  • Mark the file executable: right-click, Properties, Allow executing file as program. Or run chmod +x BridgeToGrowthLearning-x86_64.AppImage.
  • Open the file. If a WebKitGTK 4.1 library is missing, the app names the package to install.
  • Without FUSE, start it with APPIMAGE_EXTRACT_AND_RUN=1 ./BridgeToGrowthLearning-x86_64.AppImage.

Unsigned installers

The desktop workflow does not sign or notarize these installers yet. There is no Developer ID, no Apple notarization ticket, and no Authenticode signature. The first launch asks for one extra confirmation. The macOS disk image does get an ad-hoc signature, which Apple silicon requires before the app can run at all. That signature does not satisfy Gatekeeper.

  • Windows. If SmartScreen says "Windows protected your PC", choose More info, then Run anyway.
  • macOS. If macOS says it cannot verify the app, choose Done. Then open System Settings → Privacy & Security, scroll down, and choose Open Anyway next to the app's name. On macOS 14 and earlier, right-click the app in Applications and choose Open.
  • Linux. The .deb and the AppImage are unsigned. A browser or software center may warn before you open them.

Computers without an installer

Intel Macs, ARM Linux, and 32-bit systems are not part of the published set. Those computers can build the app from source. There is no auto-update. When a newer stable release is published, come back to this page or to the releases list.
